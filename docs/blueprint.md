# **App Name**: ImuTask

## Core Features:

- Task Creation: Allow clients to create tasks by specifying category, address, time slot and price.
- Offer Submission: Enable providers to submit offers with a message and price slot.
- Offer Acceptance & Escrow: Enable clients to accept offers, triggering a payment authorization (escrow).
- Automated Task Categorization: Use a tool powered by AI to automatically suggest task categories based on task description.
- Review and Dispute System: Enable bilateral reviews/ratings and a structured dispute process with moderation.
- User Authentication: Implement user authentication with email/phone verification and KYC via Stripe Connect.
- Localized Interface: Interface is presented to the user in their selected locale, among FR, EN and JP.

## Style Guidelines:

- Primary color: Soft Lavender (#E6E6FA) to evoke a sense of calm and reliability.
- Background color: Light Gray (#F5F5F5) for a clean, neutral backdrop.
- Accent color: Dusty Rose (#D8BFD8) to add warmth and a touch of sophistication.
- Body and headline font: 'PT Sans', a humanist sans-serif font suitable for headlines or body text
- Use clean, minimalist icons to represent service categories and actions.
- Emphasize a clean and straightforward layout to make navigation intuitive for all user demographics.
- Incorporate subtle animations for task status updates and booking confirmations.
