# **App Name**: ImuTask

## Core Features:

- Task Posting: Allow users to post tasks with detailed descriptions, categories, location, and budget using a multi-step form. Each step will validate the information provided.
- Provider Matching: Automatically match tasks with available and suitable service providers based on skills, location, and availability. Generative AI is used as a tool to categorize provider skills for improved searchability.
- Direct Messaging: Enable direct communication between clients and providers for discussing task details, setting expectations, and clarifying requirements.
- User Authentication: Secure user accounts with login and registration functionality.
- Profile Management: Allow users to create and manage their profiles, including personal information, skills, experience, and availability.
- Geolocation: Display task locations on a map, showing nearby providers. Providers will be matched with local tasks.

## Style Guidelines:

- Primary color: HSL(210, 60%, 50%) - RGB(51, 153, 255), a vibrant blue to convey trust and reliability.
- Background color: HSL(210, 20%, 98%) - RGB(245, 247, 249), a very light, desaturated blue for a clean, professional backdrop.
- Accent color: HSL(180, 50%, 40%) - RGB(51, 179, 179), a contrasting teal for important CTAs and interactive elements.
- Font: 'Inter', a sans-serif font, should be used throughout the app, for both headlines and body text.
- Use a set of consistent, outline-style icons to represent task categories and UI actions. The icons should be simple, modern, and easily recognizable.
- Design a clean and intuitive layout with clear content hierarchy, ample white space, and a mobile-first approach. Prioritize usability and accessibility in all design decisions.
- Use subtle animations and transitions to enhance the user experience and provide visual feedback. Keep animations short and purposeful, avoiding anything distracting or excessive.
