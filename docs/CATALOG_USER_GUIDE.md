# Guide d'Utilisation du Catalogue de Services

## Vue d'ensemble

Le système de catalogage de services d'IMU Task permet aux utilisateurs de créer, rechercher et gérer des tâches en utilisant une structure organisée de catégories, tags et templates prédéfinis. Ce guide vous aidera à tirer le meilleur parti de ces fonctionnalités.

## Comprendre les Catégories

### 🏠 Les 8 Catégories Principales

#### 1. **Aide à Domicile** (HOME_HELP)
**Quand utiliser ?**
- Vous avez besoin d'aide pour le ménage, le rangement ou l'organisation
- Vous cherchez quelqu'un pour des tâches ménagères régulières ou ponctuelles
- Vous avez besoin d'aide pour organiser un espace

**Exemples de tâches :**
- Ménage complet d'un appartement
- Rangement et organisation d'une pièce
- Repassage de vêtements
- Nettoyage de printemps
- Aide pour le tri et désencombrement

**Tarifs indicatifs :** 15-25€/heure  
**Durée typique :** 1-4 heures

**Tags associés :** `cleaning`, `ironing`, `organizing`, `deep_cleaning`, `laundry`

---

#### 2. **Livraison/Courses** (DELIVERY)
**Quand utiliser ?**
- Vous avez besoin qu'on fasse vos courses
- Vous devez faire livrer un colis ou un document
- Vous cherchez quelqu'un pour récupérer quelque chose

**Exemples de tâches :**
- Courses alimentaires au supermarché
- Récupération de colis à la poste
- Livraison de documents importants
- Achat de médicaments en pharmacie
- Transport de petits objets

**Tarifs indicatifs :** 12-20€/heure  
**Durée typique :** 30 min - 2 heures

**Tags associés :** `groceries`, `urgent_delivery`, `pick_up`, `pharmacy`, `mail`

---

#### 3. **Aide Numérique** (DIGITAL_HELP)
**Quand utiliser ?**
- Vous avez besoin d'aide avec un ordinateur, smartphone ou tablette
- Vous voulez apprendre à utiliser une application
- Vous avez un problème technique à résoudre
- Vous devez configurer un appareil

**Exemples de tâches :**
- Installation et configuration d'un smartphone
- Aide pour créer un compte email
- Formation à l'utilisation d'applications
- Résolution de problèmes informatiques basiques
- Configuration WiFi et imprimante

**Tarifs indicatifs :** 18-30€/heure  
**Durée typique :** 1-3 heures

**Tags associés :** `smartphone_setup`, `email_help`, `wifi_config`, `app_training`, `troubleshooting`

---

#### 4. **Déménagement** (MOVING)
**Quand utiliser ?**
- Vous déménagez et avez besoin d'aide pour porter
- Vous devez monter ou démonter des meubles
- Vous avez de gros objets à déplacer

**Exemples de tâches :**
- Aide déménagement d'un studio/appartement
- Montage de meubles IKEA
- Transport d'objets encombrants
- Démontage et remontage de meubles
- Portage de cartons et meubles

**Tarifs indicatifs :** 15-25€/heure  
**Durée typique :** 2-8 heures

**Tags associés :** `heavy_lifting`, `furniture_assembly`, `packing`, `loading`, `disassembly`

---

#### 5. **Accompagnement** (ACCOMPANIMENT)
**Quand utiliser ?**
- Vous avez besoin d'être accompagné à un rendez-vous
- Vous cherchez de la compagnie pour une sortie
- Vous avez besoin de quelqu'un pour vous tenir compagnie

**Exemples de tâches :**
- Accompagnement à un rendez-vous médical
- Compagnie pour une promenade
- Assistance pour des démarches administratives
- Présence et conversation à domicile

**Tarifs indicatifs :** 15-22€/heure  
**Durée typique :** 1-4 heures

**Tags associés :** `medical_appointment`, `companionship`, `admin_help`, `walking`, `supervision`

---

#### 6. **Jardinage** (GARDENING)
**Quand utiliser ?**
- Vous avez besoin d'entretenir votre jardin
- Vous voulez tondre la pelouse
- Vous devez tailler des haies ou arbustes
- Vous avez besoin d'aide pour le nettoyage extérieur

**Exemples de tâches :**

#### 7. **Garde d'Animaux** (PET_CARE)
**Quand utiliser ?**
- Vous avez besoin de quelqu'un pour promener votre chien
- Vous partez et devez faire garder votre animal

- Installation de tables et chaises pour une fête

- Démontage après un événement
- Aide cuisine pour buffet

**Tarifs indicatifs :** 15-25€/heure  
**Durée typique :** 2-6 heures

**Tags associés :** `setup`, `service`, `catering_help`, `cleanup`, `event_prep`

## Utiliser les Tags

### Qu'est-ce qu'un Tag ?

Les tags sont des étiquettes descriptives qui précisent le type exact de travail requis. Ils permettent :
- Une **recherche plus précise** des tâches
- Une **meilleure compréhension** des besoins
- Un **matching plus efficace** avec les providers

### Comment Choisir les Bons Tags ?

#### ✅ Bonnes Pratiques

1. **Soyez Spécifique**
   - ❌ Mauvais : Catégorie "Aide à domicile" sans tag
   - ✅ Bon : Catégorie "Aide à domicile" + Tags `deep_cleaning`, `organizing`

2. **Utilisez 2-4 Tags Maximum**
   - Trop de tags = confusion
   - Pas assez de tags = manque de précision
   - Sweet spot : 2-3 tags pertinents

3. **Combinez Tags Généraux et Spécifiques**
   - Tag général : `cleaning` (quoi)
   - Tag spécifique : `deep_cleaning` (comment)
   - Tag contextuel : `urgent` (quand)

### Comment Utiliser un Template ?

#### 📍 Lors de la Création d'une Tâche

1. **Accédez au formulaire de création**
   - Cliquez sur "Créer une tâche" depuis le dashboard

2. **Sélectionnez une catégorie**
   - Choisissez la catégorie appropriée dans la liste déroulante
   - Les templates correspondants apparaissent automatiquement

3. **Parcourez les templates suggérés**
   - Chaque template affiche :
     - Titre et description
     - Prix et durée suggérés
     - Tags associés

4. **Cliquez sur "Appliquer"**
   - Le formulaire se remplit automatiquement
   - Vous pouvez ensuite personnaliser les champs

5. **Personnalisez selon vos besoins**
   - Modifiez le titre si nécessaire
   - Ajoutez des détails à la description
   - Ajustez le prix et la durée
   - Complétez les autres champs (adresse, date)

#### 📍 Lors de l'Édition d'une Tâche

Les templates sont également disponibles lors de l'édition :
1. Ouvrez la page d'édition de votre tâche
2. Si vous changez de catégorie, les templates s'affichent
3. Appliquez un template pour repartir sur une base solide

### ✅ Avantages des Templates

- **Gain de temps** : Création 60% plus rapide
- **Prix cohérents** : Tarifs basés sur le marché
- **Descriptions complètes** : Pas besoin d'inventer
- **Tags pertinents** : Déjà pré-sélectionnés
- **Qualité garantie** : Formulations testées

## Créer une Tâche Efficace

### 📝 Checklist pour une Tâche Réussie

#### ✅ Étape 1 : Choisir la Bonne Catégorie
- [ ] J'ai identifié la catégorie principale
- [ ] La catégorie correspond bien au besoin
- [ ] J'ai vérifié les exemples de la catégorie

#### ✅ Étape 2 : Rédiger un Titre Clair
**Bon titre** : "Ménage complet appartement 2 pièces + repassage"  
**Mauvais titre** : "Besoin d'aide"

**Formule gagnante** :
```
[Action] + [Lieu/Objet] + [Détail optionnel]
```

**Exemples :**
- "Tonte pelouse 150m² avec ramassage"
- "Promenade chien matin 30-45 min"
- "Configuration smartphone nouveau"
- "Montage armoire PAX Ikea 3 portes"

#### ✅ Étape 3 : Décrire Précisément
**Points à inclure :**
- Contexte et situation
- Tâches spécifiques attendues
- Matériel fourni ou à apporter
- Contraintes particulières
- Résultat attendu

**Exemple de bonne description :**
```
J'ai besoin d'aide pour le ménage de mon appartement de 50m² (2 pièces). 
La cuisine et la salle de bain nécessitent un nettoyage en profondeur. 
Je fournis tous les produits et le matériel nécessaire.
Travail estimé à 2-3 heures. Accès facile, pas d'escaliers.
```

#### ✅ Étape 4 : Fixer un Prix Juste
**Consultez les fourchettes par catégorie :**
- Aide à domicile : 15-25€/h
- Livraison : 12-20€/h
- Aide numérique : 18-30€/h
- Déménagement : 15-25€/h
- Accompagnement : 15-22€/h
- Jardinage : 15-22€/h
- Garde d'animaux : 10-25€/visite
- Aide événementielle : 15-25€/h

**Facteurs d'ajustement :**
- Urgence : +20-30%
- Complexité : +15-25%
- Équipement requis : +10-20%
- Weekend/soirée : +15-25%

#### ✅ Étape 5 : Sélectionner les Tags
- [ ] 2-3 tags pertinents choisis
- [ ] Tags correspondent à la catégorie
- [ ] Tags décrivent précisément le travail

#### ✅ Étape 6 : Définir la Disponibilité
- Date de début souhaitée
- Plage horaire flexible si possible
- Durée estimée réaliste

## FAQ - Questions Fréquentes

### Général

**Q : Combien de catégories puis-je sélectionner pour une tâche ?**  
R : Une seule catégorie principale par tâche. Si votre besoin couvre plusieurs catégories, créez plusieurs tâches séparées.

**Q : Puis-je modifier la catégorie d'une tâche déjà créée ?**  
R : Oui, via la page d'édition de la tâche. Les templates correspondants à la nouvelle catégorie s'afficheront.

**Q : Les templates sont-ils obligatoires ?**  
R : Non, ils sont optionnels. Vous pouvez créer une tâche entièrement personnalisée.

### Catégories

**Q : Quelle est la différence entre "Aide à domicile" et "Jardinage" ?**  
R : "Aide à domicile" concerne l'intérieur du logement (ménage, rangement), tandis que "Jardinage" concerne les espaces extérieurs.

**Q : Où classer une tâche de nettoyage de terrasse ?**  
R : Dans "Jardinage" avec le tag `garden_cleaning`.

**Q : Mon besoin ne correspond à aucune catégorie, que faire ?**  
R : Choisissez la catégorie la plus proche et décrivez précisément votre besoin dans la description.

### Tags

**Q : Combien de tags maximum puis-je ajouter ?**  
R : Il n'y a pas de limite stricte, mais 2-4 tags sont recommandés pour la clarté.

**Q : Puis-je créer mes propres tags ?**  
R : Non, seuls les 39 tags prédéfinis sont disponibles pour garantir la cohérence.

**Q : Que faire si aucun tag ne correspond exactement ?**  
R : Choisissez le tag le plus proche et précisez dans la description.

### Templates

**Q : Les prix des templates sont-ils fixes ?**  
R : Non, ce sont des suggestions. Vous pouvez les ajuster selon votre budget.

**Q : Puis-je appliquer plusieurs templates ?**  
R : Non, un seul template à la fois. Mais vous pouvez l'appliquer puis le modifier.

**Q : Pourquoi ne vois-je pas de templates ?**  
R : Les templates n'apparaissent qu'après avoir sélectionné une catégorie dans le formulaire.

### Recherche

**Q : Comment trouver des tâches urgentes ?**  
R : Utilisez le filtre de date "Aujourd'hui" dans la recherche avancée.

**Q : Puis-je sauvegarder mes filtres de recherche ?**  
R : Pas encore, mais cette fonctionnalité est prévue dans une future mise à jour.

**Q : Les résultats sont-ils triés ?**  
R : Oui, par date de création (plus récent en premier) par défaut.

### Prix et Budget

**Q : Comment déterminer un prix juste ?**  
R : Consultez les fourchettes de prix par catégorie dans ce guide. Les templates donnent aussi de bonnes indications.

**Q : Puis-je négocier le prix après création ?**  
R : Le prix peut être discuté avec les providers intéressés avant acceptation finale.

**Q : Y a-t-il des frais de service ?**  
R : Consultez les conditions générales de la plateforme pour les détails sur les commissions.

### Performance

**Q : Pourquoi ma tâche ne reçoit pas de propositions ?**  
R : Vérifiez que :
- La catégorie est pertinente
- Les tags sont précis
- Le prix est dans la fourchette du marché
- La description est claire et complète
- La disponibilité est raisonnable

**Q : Comment augmenter mes chances de trouver un provider ?**  
R : 
- Utilisez un template pour une structure optimale
- Ajoutez 2-3 tags pertinents
- Proposez un prix dans la fourchette haute
- Soyez flexible sur les horaires
- Rédigez une description détaillée
